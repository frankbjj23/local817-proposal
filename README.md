# Local 817 website proposal

A separate website design concept prepared by **Frank Smith III** for leadership review, with a proposed home for Driver Hub.

**Presentation:** https://frankbjj23.github.io/local817-proposal/

This is not the official Local 817 website and is not presented as a union-approved replacement. The official site at https://www.local817.com/ and the protected Driver Hub at https://817driverhub.com/ remain separate, active services.

## Included

Responsive homepage, craft pages, searchable member resources, Driver Hub navigation previews, news, contact information, a source inventory, and the downloadable leadership brief. Text is centered and every logo links home.

Payments, reports and member sign-in open their existing official services. This prototype has no backend, gathers no personal information, and contains no private driver records or yard access codes. It is a public presentation; `noindex` requests search-engine exclusion and does not restrict access.

## Hosting

GitHub Pages publishes `main` branch's `/docs` folder. Relative asset paths and hash routes allow the site to run at `/local817-proposal/`.
